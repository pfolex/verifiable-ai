# Help build and independently evaluate AIX

We are building an open research system for verified reasoning, small specialist models, and eventually opt-in volunteer computing. We are looking for contributors in evaluation, probability and causal reference solvers, PyTorch, worker isolation, distributed systems, documentation, and independent reproduction.

Current status: AIX-Zero is a small experimental neuro-symbolic model. Its assisted arithmetic result is not a frontier-model benchmark. Recent frozen-base Bayesian specialists failed stronger simple controls and were rejected. Storage and dispatch experiments have measured limits. The roadmap aims to improve capability through reproducible evidence; it does not promise the world's smartest AI.

Start with one ready issue or offer review/reproduction help in the community coordination thread. State your interests and available time; no contribution obligation, compensation, appointment, or affiliation is implied. Documentation and negative-result replication are valuable contributions. Public compute enrollment will open only after isolation, verification, and consent controls are validated.

This is a reusable draft invitation. The public GitHub roadmap and community coordination issue are the initial opt-in meeting points. A maintainer should choose and approve any additional external posting destination; no external researcher is enrolled or contacted merely because this draft exists.
